# Wayfire Desktop

A personal Wayfire desktop configuration for Linux, developed on Arch Linux.

## What's included

- Wayfire configuration and performance/effects profiles
- Waybar panels and custom Go-based modules
- Rofi menus and themes
- GTK, wlogout, Fastfetch, and Alacritty configuration
- Display and wallpaper selection scripts

## Before installing

This is an initial configuration export, not yet a complete automated
installer. Review the machine-specific settings, dependencies, and scripts
before using it on another computer.

The display selector attempts to detect internal display connectors named
eDP, LVDS, DSI, or LCD. Set WAYFIRE_INTERNAL_OUTPUT if your system uses
another name.

Set WAYFIRE_WALLPAPER_DIR to override the default ~/Wallpapers directory.

The Orchis GTK theme and Papirus icons are external dependencies, not
included or claimed as original work by this project.
